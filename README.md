# Live_DBMS_AI

MariaDB의 상태와 성능 지표를 수집하고, 실시간 대시보드·위험도 판단·장애 알림을 제공하는 프로젝트입니다.

현재는 프로젝트 초기 구조와 개발 명세를 정리한 단계입니다.

## 폴더 구조

```text
Live_DBMS_AI/
├── frontend/       # 프론트엔드 코드
├── backend/        # 백엔드 코드
└── docs/           # 요구사항·API·이벤트 명세 및 협업 문서
```

## 실행 안내

실행 가능한 애플리케이션은 아직 구성되지 않았습니다. 기술 스택과 개발 환경이 확정되면 설치·실행 방법을 추가합니다.
